# DevTool Gallery 网站规划

这版目标不是 01MVP 内容站，而是类似 MonkeyCode Showcase 的个人工具作品集：用卡片网格展示工具、项目、分类、状态和入口。

## 网站定位

把你做过、正在做、准备做的开发辅助工具集中展示。每个工具都应该有：

- 封面图或界面截图。
- 名称。
- 分类。
- 当前状态。
- 简短说明。
- 在线体验、文档或 GitHub 入口。

## 首页结构

1. Hero
   - 标题：我的开发工具展厅。
   - 搜索框：支持按 Linux、Docker、日志、模板等关键词筛选。
   - 精选项目：Linux 远程控制面板。

2. Showcase 网格
   - 类似 MonkeyCode 用户作品集。
   - 支持分类筛选。
   - 卡片展示封面、状态、分类、介绍和入口。

3. 重点项目详情
   - Linux 远程控制面板作为第一批主打项目。
   - 用模拟控制台界面展示产品形态。

4. 后续迭代
   - 工具做出来后替换真实截图。
   - 添加真实在线地址和源码地址。
   - 增加更新日志和访问统计。

## 首批工具规划

- Linux 远程控制面板：MVP 首发。
- Docker Compose 助手：规划中。
- Nginx 配置生成器：想法池。
- 日志定位助手：规划中。
- 端口与进程诊断：规划中。
- Runbook 模板库：可先做。
- 环境变量检查器：想法池。
- SQL / Redis 快查：想法池。

## 第一版重点

第一版最重要的不是工具数量，而是让网站看起来像一个持续更新的产品展厅。先用规划卡片撑起结构，之后每完成一个工具，就把卡片从“规划中”改成“可体验”。

## 视觉方向

- 参考 MonkeyCode Showcase：大标题、搜索、分类筛选、项目卡片网格。
- 不再做 01MVP 那种纯栏目卡片页。
- 小黑插画只作为辅助封面，不抢主视觉。
- 真正的主视觉应该逐步替换成工具截图。
