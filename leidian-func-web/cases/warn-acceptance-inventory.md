# 预警运行验收用例说明（按需求，不按实现细节纠结）

本包用例描述**业务验收标准**：给定前置（配置规则/抑制/因子）→ 触发评估 → 断言事件/抑制效果/通知结果。

- 默认 `skip: true`：能力未上线也能先当验收清单维护。
- 上线后：取消 skip；若路径/字段名与实现不一致，只改 path/字段，**不断言口径**。
- 统一调试入口约定：`POST /warning/eval/trigger`（siteId + factors）；正式环境也可等价替换为消息触发。

## 验收主题

| 主题 | 用例 | 验收要点 |
|------|------|----------|
| 命中/未命中 | wg-01/02/03 | 达标出事件；未达标/停用不出 |
| NONE | wg-04 | RECORDED，无通知 |
| 未就绪 | wg-05 | 不误报 |
| 版本 | wg-06 | item 钉住 versionId |
| FULL/NOTIFY_ONLY | wg-10/11 | SUPPRESSED vs 可见不通知 |
| 目标匹配 | wg-12/13/14 | 等级/设备/AND；纯气象不误伤 |
| 生命周期 | wg-20~26 | 生成/归并/升级/续期/降级/解除/确认 |
| 查询可见性 | wg-30~33 | 筛选/详情/时间线/SUPPRESSED 视角 |
| 黄金路径 | wg-40/41 | 命中与 FULL 抑制端到端 |
| 通知 | wn-* | 确认任务、投递、否定、重试 |
| 因子 | wf-* | 种子/筛选/内置保护/WINDOW 校验 |
| 回测 | wb-* | 启用可测、草稿拒绝、无正式事件副作用 |

配置 CRUD 主路径仍在 `warn-rule-*` / `warn-suppress-*`，本说明不重复。
