## 2. 能力设计

### [C01] 按模块维护用例

- **涉及模块**：操作台前端、用例仓库
- **数据流转**：前端按模块展示分组；仓库按模块加载用例列表供展示与筛选
- **关键状态变化**：无
- **不做什么**：不做跨模块拖拽迁移；首期模块固定为预警规则配置与压住预警

### [C02] 增删改用例

- **涉及模块**：操作台前端、本地控制服务、用例仓库
- **数据流转**：前端提交用例内容 → 控制服务校验后写入用例仓库 → 列表刷新
- **关键状态变化**：无
- **不做什么**：不做多人协同编辑锁；不做用例审核流

### [C03] 勾选批量执行

- **涉及模块**：操作台前端、本地控制服务、执行引擎、用例仓库
- **数据流转**：前端提交勾选 id 列表 → 控制服务从仓库取用例 → 交给执行引擎按序跑 → 回传进度与汇总
- **关键状态变化**：空闲 → 跑批中 → 结束（成功汇总/失败汇总）；跑批中拒绝开启第二批
- **不做什么**：不做按标签智能选集；不做分布式并行工人

### [C04] 逐条结果展示

- **涉及模块**：操作台前端、执行引擎
- **数据流转**：执行引擎产出每条通过/失败/跳过及原因与响应摘要 → 前端表格展示
- **关键状态变化**：单条：待执行 → 执行中 → 通过/失败/跳过
- **不做什么**：不做与预期响应的可视化 diff 编辑器

### [C05] 历史执行记录

- **涉及模块**：操作台前端、本地控制服务、跑批历史
- **数据流转**：跑批结束写入历史 → 前端列表选择某次 → 控制服务读出明细
- **关键状态变化**：无
- **不做什么**：不做跨机器同步历史；不做自动清理策略配置台

### [C06] 被测环境配置

- **涉及模块**：操作台前端、本地控制服务、环境配置
- **数据流转**：前端填写 Base URL 与登录凭证 → 控制服务写入环境配置 → 执行引擎读取后出站
- **关键状态变化**：无
- **不做什么**：不做多环境配置档案切换（可后续加）；不做自动探测服务健康以外的复杂探活编排

### [C07] 预警规则用例包

- **涉及模块**：用例仓库、执行引擎
- **数据流转**：仓库提供内置规则用例 → 执行引擎按步骤请求 `/warning/rules` 相关能力并判定
- **关键状态变化**：无（业务侧规则状态变化属被测系统）
- **不做什么**：不在本工具内实现规则审核流；不覆盖评估引擎命中类场景

### [C08] 压住预警用例包

- **涉及模块**：用例仓库、执行引擎
- **数据流转**：仓库提供内置压住预警用例；执行时若标记跳过则直接记跳过原因，否则按步骤请求并判定
- **关键状态变化**：无
- **不做什么**：不在本工具内实现审批人模拟 UI；不伪造业务库抑制数据

### [C09] PERF 同款界面

- **涉及模块**：操作台前端
- **数据流转**：静态样式与布局直接呈现；无业务数据变换
- **关键状态变化**：无
- **不做什么**：不做像素级对照测试；不复制 PERF 的造数/SQL 压测页

### [C10] 用例文件

- **涉及模块**：用例仓库、本地控制服务
- **数据流转**：增删改最终落为模块目录下的用例文件；启动时从文件加载
- **关键状态变化**：无
- **不做什么**：不做用例二进制打包格式；不做与业务 Flyway 的自动同步

### [C11] 自动请求接口并判定

- **涉及模块**：执行引擎、环境配置、本地控制服务
- **数据流转**：控制服务触发 → 执行引擎读环境 → 逐步 HTTP → 用判定条件核对 → 汇总结果
- **关键状态变化**：同 C03/C04 的跑批与单条状态
- **不做什么**：不做浏览器 UI 自动化；不支持非 HTTP 协议
